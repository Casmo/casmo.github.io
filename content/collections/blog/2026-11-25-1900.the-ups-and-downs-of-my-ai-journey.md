Back in June I wrote about [my love/hate relation with AI](/read/my-lovehate-relation-with-ai-llm/). Looking back, "relation" was the wrong word. It was a rollercoaster. Love, hate, love, hate, and somewhere along the way the line started going up and hasn't stopped since.

So here it is. The ups and the downs, beat by beat.

**1. ChatGPT 3.5: surreal (love)**
The first time I typed something into ChatGPT, it felt unreal. A chatbot that didn't spit out canned replies but actually _answered_. I gave it questions I was sure nobody had asked before, and it answered those too. And then it wrote a snippet of code. Not great code, not always working code, but code. Weird. I loved it.

**2. Copilot: it is reading my mind (love)**
Then came Copilot autocomplete in VS Code. I'd start typing a function name and the rest was already there, greyed out, waiting for a tab. Sometimes, no, _often_, it felt like it was reading my mind. Strange and awesome at the same time. For the first time an AI was not a website I visited, but a part of my editor.

**3. Cursor: an agent in the side panel (meh)**
Cursor put an agent next to my code. You could ask it to change things across files, and it would. Awkward at times, interesting at others. It worked well when the task was small and fell apart when it wasn't. I was curious, but not convinced.

**4. Early Claude Code: more frustration than help (hate)**
Then I moved to the terminal with the early versions of Claude Code. In theory: an agent that could do everything. In practice: an agent that did _something_. Confidently. I spent more time cleaning up and explaining than I would have spent writing it myself. More frustrated than helpful.

**5. Opus 4 and 4.5: the rollercoaster (love, hate, love, hate)**
Then the models got better, and things really took off. One day it fixed a bug I had expected to spend a whole day on, in ten minutes. The next day it rewrote half a module I never asked it to touch. Love. Hate. Love. Hate. The highs were higher than ever, and that made the lows hurt more. And on top of that, [the same question could give a completely different answer](/read/heisenberg-context-prompt/).

**6. Overwhelmed and underwhelmed (hate)**
This was the bottom of the graph. Every week there was a new model, a new tool, a new MCP server, a new IDE, a new set of skills I _really_ needed to use. I tried them myself, I tried what others swore by. As I wrote [back then](/read/create-a-perfect-ai-colleague/): _"every week I was reminded about a new revolutionary app I really needed to use. Either I was too confused about what all these new features meant, or I'm just too old school."_ And: _"There are hundreds of thousands of skills ready to be injected into your workflow. Why? It just feels like AI slop."_

Overwhelming in choice. Underwhelming in results.

**7. The AIHero skills: life changing (love)**
Then I found the skills from Matt Pocock at [AIHero.dev](https://www.aihero.dev/). A handful of prompts, nothing more. `/grill-with-docs`, `/to-prd`, `/to-issues`, `/tdd`. They all work around one principle: make sure we understand each other exceptionally well, and work towards a common goal. The agent grills _me_ before it writes a single line. Most, if not all, of my frustrations were gone. Not because the model changed, but because the conversation did. I wrote more about it in [Create a perfect AI colleague](/read/create-a-perfect-ai-colleague/).

**8. Superpowers: a detour (love)**
For a while I switched to Superpowers, a bigger collection of skills built around the same idea: think first, plan next, build last. A good while. And it taught me something too: it is not about which skills you pick, it is about the principle behind them.

**9. Building my own tools: human-loop (love)**
Once that principle clicked, I started building my own tools around it. The biggest one is human-loop. It runs coding agents (Claude Code, OpenCode, Codex) through workflows you draw as boxes and arrows: triage, mockup, spec, build, review, release notes. Each run gets its own copy of the code.

![A human-loop workflow: a request goes to a build agent, a design QA subflow checks the result and sends remarks back to a fix agent](/assets/blog/ai-journey/human-loop-workflow.webp)

The agents do the work, and whenever a decision is needed, the run stops and asks a human. Questions, approvals, mockups and screenshots all land in one inbox, also on my phone. If an agent gets lost, I take over its session in the browser, steer it, and hand it back. A run can wait minutes or days for me.

![The human-loop inbox: approvals and a question from an agent, waiting live for an answer](/assets/blog/ai-journey/human-loop-inbox.webp)

Or, as the tagline says: _AI agents do the work. You stay in control._

This is where the output really exploded. I'm no longer sitting next to a terminal watching an agent type. Workflows run in parallel, and I only step in where I'm actually needed.

**10. You cannot think big enough (sky high)**
And here is the thing I didn't expect: output alone is not enough. I wrote about it in [Can you think big enough?](/read/can-you-think-big-enough/), about [the bubble we're all running in](/read/are-we-all-running-inside-our-own-bubble/) and in [Raise the ceiling](/read/raise-the-ceiling/). More features, faster, is the floor. Not the ceiling.

The same tools that write the features can also make the code better. Stronger tests. Security checks on every change. Cleaner code than I used to write myself. And they can make the way we _present_ our work to customers better: not a changelog nobody reads, but a mockup, a video, an interactive walkthrough of what changed and why.

So the ceiling should not just be higher. It should be sky high.

**Where the line goes next**
If you'd draw my AI journey as a graph (and [I did](/assets/pages/the-ups-and-downs-of-my-ai-journey.png)), it goes up and down like a heart monitor. The love/hate is still there, and I don't think it will ever fully go away. But the line keeps going up. And for now, I can't see where it ends.

**One more thing**
I'm already working on what comes after the workflows. No name yet, nothing to announce. Just a small demonstration: every character below is an agent. Some walk to their desk when they pick up work, some are typing away, others are walking around waiting for their next task.
